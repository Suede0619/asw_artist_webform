# ArtSouthwest artist intake

This is the independent `Suede0619/asw_artist_webform` repository. Use React and Vite for the form and review interface, Express for the API, Neon for the production migration target, and the approved publication feed for the catalog. Read [README.md](README.md) and [DEPLOYMENT.md](DEPLOYMENT.md). Check the actual origin and storage before any migration or deployment.

In the ART workspace, follow `../../AGENTS.md` and `../AGENTS.md`. Before reporting any task complete, log the date in America/Denver, work, hours and evidence in `../../private/TIMESHEET.md`. Use reported time when available, label estimates, reconcile the totals, and keep the file out of Git. Update the workflow handoff with deployment and validation results.

Use fictional data for testing. Contact details, originals, logs, test credentials and backups belong in private ignored storage. The artist owns their draft. Staff approval writes a separate public version with approved media and public contact fields. Verify that a sale or withdrawal removes the applicable work or profile. Keep the artist and staff session boundaries intact. Run the build and relevant API and browser tests before publishing changes.
